# Pharmacy Drug Inventory System — CA235 Group 13

Full-stack coursework project: Spring Boot + ReactJS + PostgreSQL + JWT security.

Medicine stock management with expiry date tracking, low-stock & expiry alerts,
prescription record management, supplier order logging, and monthly sales reports.

## Structure

```
pharmacy-backend/    → Spring Boot API (see its README for setup + endpoints)
pharmacy-frontend/   → React frontend (see its README for setup)
```

Each folder has its own README with setup instructions specific to that part.

## Roles

- `ADMIN` — full access
- `PHARMACIST` — day-to-day stock, sales, prescriptions
